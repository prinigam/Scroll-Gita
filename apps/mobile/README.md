# Mobile reader

Run commands from the monorepo root; see [the project README](../../README.md) for setup, checks, native-build requirements and known limitations.

Routes are in `src/app`; components, local repositories, migration initialization, theme tokens and transient Zustand state are separate. Bundled content lives in `assets/content` and is generated by `npm run content:build`.

All bundled text is explicitly non-scriptural layout data. Do not ship it as production content.
